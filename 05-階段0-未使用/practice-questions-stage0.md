## 題目（給同學看）

每題的題目都是「這段程式會印出什麼？」

### 第 1 次

#### A1 · 字串與數字

```python
a = "3"
b = "4"
print(a + b)
```

- (A) 7
- (B) 34
- (C) 12
- (D) 會出現錯誤

#### B1 · range 和 for（每個數字印一行）

```python
for i in range(3):
    print(i)
```

- (A) 0 1 2 3
- (B) 1 2 3
- (C) 3
- (D) 0 1 2

#### C1 · if/elif

```python
x = 7
if x > 10:
    print("A")
elif x > 5:
    print("B")
elif x > 3:
    print("C")
else:
    print("D")
```

- (A) C
- (B) B
- (C) B 和 C
- (D) D

### 第 2 次

#### D1 · list 索引

```python
fruits = ["蘋果", "香蕉", "橘子"]
print(fruits[1])
```

- (A) 蘋果
- (B) 香蕉
- (C) 橘子
- (D) 會出現錯誤

#### A2 · 字串與數字

```python
age = "18"   # input() 拿到的都是字串
print(age + 1)
```

- (A) 19
- (B) 181
- (C) 會出現錯誤
- (D) 18

#### B2 · range 和 for

```python
total = 0
for i in range(1, 4):
    total = total + i
print(total)
```

- (A) 10
- (B) 3
- (C) 6
- (D) 4

### 第 3 次

#### C2 · if/elif

```python
x = 7
if x > 5:
    print("A")
if x > 3:
    print("B")
```

- (A) 先印出 A，再印出 B
- (B) 只印出 A
- (C) 只印出 B
- (D) 什麼都不印

#### D2 · list 索引

```python
nums = [5, 10, 15]
print(nums[3])
```

- (A) 15
- (B) 5
- (C) 會出現錯誤
- (D) 30

#### A3 · 字串與數字

```python
n = int("7")
print(n * 3)
```

- (A) 21
- (B) 777
- (C) 會出現錯誤
- (D) 73

### 第 4 次

#### B3 · range 和 for

```python
print(list(range(0, 10, 3)))
```

- (A) [0, 3, 6, 9]
- (B) [3, 6, 9]
- (C) [0, 3, 6]
- (D) [0, 3, 6, 9, 12]

#### C3 · if/elif

```python
x = 2
if x > 5:
    print("A")
    print("B")
print("C")
```

- (A) 只印出 C
- (B) A、B、C
- (C) B、C
- (D) 什麼都不印

#### D3 · list 索引

```python
nums = [1, 2, 3, 4, 5]
print(nums[-2])
```

- (A) 2
- (B) 5
- (C) 會出現錯誤
- (D) 4

## 答案與解說

所有答案都在本機用 Python 執行確認過（2026-11-08）。解說會在交卷後由表單顯示，也可以在階段 1 當作事先寫好的說明（prd FR-3）。

| 題號 | 答案 | 解說 |
|---|---|---|
| A1 | **(B) 34** | `"3"` 和 `"4"` 都是字串，`+` 是把兩段字串接起來，不是數學相加 |
| B1 | **(D) 0 1 2** | `range(3)` 從 0 開始、不包含 3，所以是 0、1、2 |
| C1 | **(B) B** | 由上往下檢查，`x > 5` 第一個成立就印 B，後面的 `elif`、`else` 都不會再檢查 |
| D1 | **(B) 香蕉** | 索引從 0 開始，`[1]` 是第 2 個 |
| A2 | **(C) 會出現錯誤** | 字串不能直接加數字（TypeError），要先用 `int(age)` 轉成數字 |
| B2 | **(C) 6** | `range(1, 4)` 是 1、2、3（不包含 4），加起來是 6 |
| C2 | **(A) 先印出 A，再印出 B** | 這是兩個獨立的 `if`，不是 `elif`，兩個都會檢查，兩個都成立 |
| D2 | **(C) 會出現錯誤** | 3 個元素的索引是 0～2，`[3]` 超出範圍（IndexError） |
| A3 | **(A) 21** | `int("7")` 已經把字串轉成數字 7，所以是數學相乘；對照 concierge 第 1 題 `"5" * 2` 是 55 |
| B3 | **(A) [0, 3, 6, 9]** | 從 0 開始每次加 3，到 10 之前停下，不包含 10 |
| C3 | **(A) 只印出 C** | 有縮排的兩行都在 `if` 裡面，條件不成立就都不執行；`print("C")` 沒有縮排，一定會執行 |
| D3 | **(D) 4** | 負數索引從後面數，`[-1]` 是最後一個，`[-2]` 是倒數第 2 個 |

答案分布：(A) 4 題、(B) 3 題、(C) 3 題、(D) 2 題。
