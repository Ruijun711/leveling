## 題目（給同學看）

### 第 1 題 · 字串與數字

```python
x = "5"
y = 2
print(x * y)
```

這段程式會印出什麼？

- (A) 10
- (B) 55
- (C) 7
- (D) 會出現錯誤

### 第 2 題 · 縮排

```python
for i in range(3):
    print("A")
print("B")
```

這段程式會印出什麼？

- (A) 印出 A、A、A，最後印出 1 次 B
- (B) A 和 B 交替印 3 次
- (C) 印出 A、A、A、B、B、B
- (D) 只印出 B

### 第 3 題 · if / elif

```python
score = 85
if score >= 60:
    print("及格")
elif score >= 80:
    print("良好")
else:
    print("不及格")
```

這段程式會印出什麼？

- (A) 及格
- (B) 良好
- (C) 及格 和 良好 都會印出
- (D) 不及格

### 第 4 題 · range

```python
print(list(range(1, 5)))
```

這段程式會印出什麼？

- (A) [1, 2, 3, 4, 5]
- (B) [0, 1, 2, 3, 4]
- (C) [1, 2, 3, 4]
- (D) [2, 3, 4, 5]

### 第 5 題 · list

```python
nums = [10, 20, 30]
nums.append(40)
print(nums[1] + nums[-1])
```

這段程式會印出什麼？

- (A) 50
- (B) 60
- (C) 70
- (D) 會出現錯誤

## 答案與解說（Avi 用，不要發給同學）

所有答案都在本機用 Python 執行確認過（2026-11-05）。

| 題號 | 答案 | 解說 |
|---|---|---|
| 1 | **(B) 55** | `x` 是字串 `"5"`，字串乘以 2 是重複兩次，不是數學相乘 |
| 2 | **(A)** | `print("B")` 沒有縮排，不在迴圈裡，所以迴圈跑完才印 1 次 |
| 3 | **(A) 及格** | 85 ≥ 60 先成立，後面的 `elif` 就不會再檢查 |
| 4 | **(C) [1, 2, 3, 4]** | `range(1, 5)` 包含 1、不包含 5 |
| 5 | **(B) 60** | `nums[1]` 是 20，`append` 後 `nums[-1]` 是 40 |
